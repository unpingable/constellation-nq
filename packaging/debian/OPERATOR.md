# Constellation NQ package

NQ evaluates bounded questions from enrolled observations. A result does not
authorize an effect. Installation is inert: it creates no configuration, store,
helper admission or enabled collector.

The prepared combined candidate targets Ubuntu 22.04 amd64. Use its source-free
[operator guide](https://github.com/unpingable/unpingable-site/blob/dev/operator-beta/constellation/combined-candidate/README.md) for download verification, exact package installation,
separate enrollment, Workbench, currentness and day-two recovery. It is a neutral
owner-review candidate; BC1 is not tagged or published. Component source alone
does not install the composed product or grant authority.

Use `nq --version` and `nq --build-info` for native identity, and `dpkg-query -W
nq-ng` for package identity. Native version0.2.5 and a Debian packaging revision
are distinct. Checksums in the candidate identify exact installed bytes.

See [package operation](OPERATIONS.md) and the installed examples directory.
