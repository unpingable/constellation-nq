# NQ diagnostic-execution contract v2

This directory is the repository-native, language-neutral distribution surface
for `nq.diagnostic_execution.v2`. It is a sibling of the frozen
`diagnostic-contract/` v1 boundary, not a replacement for it. Consumers must
dispatch by the exact schema identity and must never decode v2 through the v1
shape.

V2 preserves distinctions that v1 could not carry:

* acquisition clocks are explicitly `bounded` or `unqualified`;
* received-input and diagnostic refusals retain complete
  `nq.governed_refusal.v1` carriers;
* multiple input refusals remain an exact frontier rather than one selected
  summary;
* acquisition failures retain the complete typed acquisition outcome, provider
  intake identity, attempt interval, and an explicit no-retained-bytes claim;
* received-input custody cannot predate its acquisition, and a contributing
  attempt cannot change the diagnostic attempt's clock qualification;
* claims can cite selected inputs, exact refusal identities, and exact failure
  identities independently; and
* unsupported outcomes carry typed, identified causes.

`manifest.json` closes and hashes the public schema and corpus. Files under
`fixtures/valid` are exact RFC 8785 canonical artifacts emitted by the Rust v2
contract and accepted by its strict decoder. Files under `fixtures/hostile` are
canonical, self-identified candidate artifacts generated by mutating that Rust
corpus; each is rejected by either a named structural rule or a named Rust
semantic invariant. The two detector refusal fixtures deliberately share the
same refusal code while differing in structured detail, proving that the detail
cannot be laundered away.

`verify_assets.py` checks the exact source or staged inventory, strict JSON,
closed Draft 2020-12 schema, canonical bytes, artifact self-identities, manifest
digests, semantic hostile-vector results, and cross-fixture relationships. JSON
Schema establishes structure only. The Rust validator remains the executable
semantic authority.

Release assembly publishes this sibling boundary under:

```text
share/nq/diagnostic-contract-v2/
```

The outer release `share/nq/MANIFEST.sha256` commits to those installed bytes.
A consumer must independently bind the outer package/release digest, this
asset manifest's digest, the exact NQ source or immutable release identity, and
the exact diagnostic artifact bytes. This inner manifest is intentionally
repository-agnostic.

Neither schema validity nor a diagnostic disposition establishes producer
authentication, current clock comparability, consumer reliance, operational
standing, authorization, dispatch, or action. Live emission must validate
current admissions and compiled profiles before constructing a v2 artifact;
historical reopening intentionally validates the frozen transport without
requiring a retired profile to remain compiled.
