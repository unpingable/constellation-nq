This document is an internal engineering index, not a public ontology. It
tracks where each inherited runtime law is enforced, the hostile test that
guards it, and the current formalization status. File and test names are the
stable references; line numbers are deliberately omitted.

## Audit rule

An invariant is not “formally proved” merely because a Rust test exists, and a
binary/profile digest is never substituted for a qualification result. When a
relevant Lean theorem is actually supplied, this crosswalk must identify its
exact declaration and the assumptions connecting it to the runtime enforcement
point.
